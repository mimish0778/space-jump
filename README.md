# SPACE JUMP

宇宙を転がりながら、迫ってくるトゲトゲをジャンプでかわし続けるワンボタンのアクションゲームです。どこまで進めるか（m）を競います。

Three.js で作ったブラウザ版で、もともと C / OpenGL で書いたゲーム（[space-jump-opengl](https://github.com/mimish0778/space-jump-opengl)）を移植したものです。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（Three.js は CDN から読み込むので、ネット接続が必要です）。

1. タイトル画面でボタンを押すと、ロケットが発進してワープしながらステージへ
2. キャラクターは自動で進むので、トゲが来たらタイミングよくジャンプ
3. 当たるとキャラがバラバラに吹き飛んでゲームオーバー。少しするとタイトルに戻ります

### 操作

| 操作 | タイトル画面 | プレイ中 |
|---|---|---|
| `Space` / `↑` / クリック / タップ | スタート | ジャンプ |

ジャンプ中にもう一度ジャンプすることはできません。

### スコア

進んだ距離がそのままスコア（m）になります。ベストは左上に表示され、更新すると黄色く光ります。ハイスコアは保存していないので、ページを再読み込みするとリセットされます。

## つくり

すべて `index.html` 1 ファイルにまとまっています。

- キャラクター・トゲ・ロケットは画像やモデルデータを使わず、球・円柱・箱・円錐の組み合わせで作っています。見た目はファイル先頭付近の `*_PARTS` 定義と `MAT`（マテリアル）で変えられます。
- 画面はタイトルとプレイの 2 シーン構成で、間をフェードとワープの演出でつないでいます。演出は 3D とは別の 2D Canvas に描いています。
- スコアなどの表示は HTML 要素を重ねたもので、700×420 の比率を保ったままウィンドウに合わせて拡大縮小します。

### 調整したい場合

ファイル先頭の定数をいじると遊び心地が変わります。

| 定数 | 内容 |
|---|---|
| `SPIKE_SPEED` | トゲが流れてくる速さ（＝スコアの伸び方） |
| `SPIKE_MIN_GAP` / `SPIKE_MAX_GAP` | トゲ同士の間隔（この範囲でランダム） |
| `JUMP_SPEED` / `GRAVITY` | ジャンプの高さと落ちる速さ |
