# SPACE JUMP

Three.js で制作した横スクロール型ジャンプアクションゲームです。スパイクを飛び越えながら距離を伸ばすことを目指します。

## 概要

- ファイル: `index.html`（Three.js r128 をCDNからESMインポート、他の外部ライブラリ不要）
- タイトル画面 → ロケットのワープ演出 → プレイ画面 → 衝突でゲームオーバー → タイトルへフェード復帰、という一連のシーン遷移を1ファイルで実装
- ハイスコアはブラウザセッション中のみ保持（ページをリロードするとリセット）

## 遊び方

1. ブラウザで `index.html` を開く
2. タイトル画面で **スペースキー / ↑キー / クリック / タップ** のいずれかを入力するとロケットが発進し、ワープ演出を経てゲームが始まる
3. プレイ中は同じ操作（スペース/↑/クリック/タップ）でジャンプし、迫ってくるスパイクを飛び越える
4. スパイクに衝突するとゲームオーバー。爆散エフェクトの後、タイトル画面へフェードして戻る
5. 到達した距離(m)がスコアとなり、最高記録は画面左上に表示される

## 画面・演出

| 要素 | 説明 |
|---|---|
| タイトルロゴ | 「SPACE-JUMP」のネオン風テキストとタイトルバウンド演出 |
| プロンプト | 「Push to Start!」の点滅表示と操作キー案内 |
| ロケット | タイトルではスピン&バウンドしながら待機、発進後は加速して画面奥へワープ |
| ワープ演出 | 同心円状のリングエフェクト＋フラッシュで場面転換を表現 |
| プレイヤー | 球体＋腕＋顔パーツで構成されたキャラクター。ジャンプ中は回転、待機中はバウンドするアニメーション |
| スパイク（障害物） | トゲ付きの球体キャラクター。奥行き方向につぶれた形状で複数体が横一列に流れてくる |
| 星背景 | 発光マテリアルの粒子がスクロールし続ける宇宙空間演出 |
| 衝突時演出 | カメラシェイク＋プレイヤーが各パーツに分解して吹き飛ぶパーティクル演出 |
| ゲームオーバー画面 | 赤いネオン風テキストとスコア表示（フェードイン/アウト） |
| ハイスコア更新演出 | 自己ベスト更新時にハイスコア表示が黄色く光る |

## 技術的なポイント

- **シーン管理**: `SCENE.TITLE` / `SCENE.PLAY` の2状態＋`TX`（トランジション）オブジェクトで、フェードとワープの2種類の画面転換を管理
- **3Dモデル**: プレイヤー・スパイク・ロケットはすべて基本ジオメトリ（球・円柱・箱・円錐）の組み合わせで構築し、パーツ定義配列(`PLAYER_PARTS`など)からメッシュを自動生成
- **HUD**: DOM要素（`#hud`）をCanvasの3D描画とは別レイヤーで重ね、CSSの`transition`でフェード演出。スコア表示など変化した値だけを更新する差分更新方式
- **トランジション描画**: `transition-canvas` という2D Canvasにワープリング・フラッシュ・フェード用の矩形を毎フレーム描画
- **パーティクル(爆散)**: 衝突時にプレイヤーの各パーツを複製し、簡易物理（重力・バウンド・減衰）で吹き飛ばして自然消滅させる
- **レスポンシブ対応**: 固定アスペクト比（700×420）を維持したまま、ウィンドウサイズに応じてレンダラーとHUDをスケーリング
- **入力**: キーボード（スペース/↑）、クリック、タッチの3系統に対応

## カスタマイズのヒント

- スパイクの出現間隔は `SPIKE_MIN_GAP` / `SPIKE_MAX_GAP` で調整可能
- 難易度（スクロール速度）は `SPIKE_SPEED` と `STAR_SPEED_PLAY` を変更
- ジャンプの高さ・重力感は `JUMP_SPEED` / `GRAVITY` で調整
- プレイヤー・スパイク・ロケットの見た目は各 `*_PARTS` 定義や `MAT`（マテリアル）オブジェクトを編集することで変更できる
- ワープ演出のリング数・速度は `TX_RING_NUM` / `TX_WARP_OUT_MS` などの定数で調整可能

## 注意点・制限事項

- Three.js r128 を使用しているため、`THREE.OrbitControls` は含まれておらず、`CapsuleGeometry` など新しいジオメトリも未対応です
- ハイスコアは `localStorage` 等に保存されておらず、ページを再読み込みすると失われます（永続化したい場合は保存処理の追加が必要）
- モバイル端末でのパフォーマンスは端末のGPU性能に依存します
